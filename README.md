# 🎓 CAPSTONE 68 – Educational Explainer Video Series with AI Avatar

## 📌 Project Overview

The **Educational Explainer Video Series with AI Avatar** is an AI-powered educational content creation project designed to produce short, engaging, and easy-to-understand explainer videos for junior students and self-learners.

This project explores how AI avatar and voice-generation technologies can be used to explain technical concepts through narration, visuals, and structured educational content.

The project uses **Machine Learning** as its demonstration topic and develops a series of three educational explainer videos.

## 🎯 Project Objectives

- Create educational explainer videos using AI avatars.
- Research AI avatar and text-to-speech technologies.
- Convert technical topics into simple explanations.
- Generate AI-powered voice narration.
- Combine narration, visuals, and subtitles.
- Evaluate video quality through viewer feedback.
- Verify the accuracy of educational content.

## 👥 Target Audience

- Junior college students
- Beginners learning Artificial Intelligence
- Self-learners
- Students interested in Machine Learning

## 🎬 Video Series

The project consists of three educational videos.

| Video | Topic | Description |
|---|---|---|
| Video 1 | What is Machine Learning? | Introduction, definition, examples, and applications |
| Video 2 | How Does Machine Learning Work? | Data collection, preprocessing, training, and prediction |
| Video 3 | Types of Machine Learning | Supervised, unsupervised, and reinforcement learning |

**Target duration:** Approximately 2 minutes per video.

## 🛠️ Technologies and Tools

- **ChatGPT / Gemini / Claude:** Research, content development, and script preparation.
- **HeyGen:** AI avatar video generation.
- **ElevenLabs:** AI voice generation.
- **CapCut:** Video editing and subtitles.
- **Microsoft PowerPoint / Gamma:** Presentation creation.
- **Python:** Subtitle generation automation.
- **Microsoft Excel:** Feedback collection and analysis.

*Tool availability, pricing, and free-plan limits may vary.*

## ⚙️ Project Workflow

1. Select the educational topic and target audience.
2. Research explainer-video structure and AI tool capabilities.
3. Prepare educational scripts.
4. Verify technical information using reliable sources.
5. Generate AI voice narration.
6. Create AI avatar videos.
7. Add relevant images, visuals, and subtitles.
8. Edit and export the final videos.
9. Collect feedback from at least five viewers.
10. Conduct a knowledge quiz.
11. Analyse the feedback and verify project results.
12. Prepare the final project presentation.

## 🐍 Python Automation

The project includes a Python-based subtitle generation utility.

### Run the automation

```bash
python --version
```

Navigate to the Automation folder:

```bash
cd Automation
```

Check the available arguments:

```bash
python generate_subtitles.py --help
```

Follow the instructions in `Automation/README.txt` to generate subtitle files.

**Note:** Generated subtitle timestamps are estimates and must be synchronized manually with the final narration.

## 📊 Testing and Evaluation

The project uses the following evaluation methods:

- Educational content accuracy verification.
- AI voice and avatar quality review.
- Subtitle synchronization testing.
- Viewer feedback collection.
- Ten-question knowledge assessment.
- Final presentation and demonstration.

Feedback and verification templates are included in the project package. Actual results must be collected and entered after testing.
